The source table
R’s UCBAdmissions table records 4,526 graduate-school applicants across Berkeley’s six largest departments in 1973. Each source cell counts applicants by admission decision, department and the historical gender label.


The demo pins the R 4.5.1 array, checks its SHA-256 and converts it into 12 department–gender rows. Each row carries two counts. All figures in this demo use those 24 original cells.

The audit boundary
Each constructed export can retain all six departments or one whole department. This leaves seven candidate scopes. The collector sends the observation to Claude and executes its allowlisted queries on a read-only SQLite connection.
A separate evaluator holds the generating filters. It checks every candidate against the visible evidence using integers, then replays each logged query. “Complete evidence” requires all seven candidates to be checkable from returned rows.
The demo tests scope recovery on one public table. The results do not estimate discrimination, causal effects or agent reliability on new datasets.
