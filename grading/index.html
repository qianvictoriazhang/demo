      Evaluation

      Protocol

      One problem, two grading conditions

      All student work is invented. The AI project team prepared the exercise, reference decisions and software, and froze the key before collecting Claude responses. The scores shown here use the AI team’s reference key. Independent faculty ratings are pending. A second AI assistant applied the rubric without seeing the key or Claude results and agreed on all 10 held-out routes and 45 marks.

      Both conditions received the same assignment, rubric, ordered responses and output format. Direct grading had no tools. The calculator condition could request numeric expressions, receive their computed values, then submit scores. The grading prompt never contained the reference decisions.

      Two development examples and ten held-out examples were recorded in independent sessions. The tests were submitted as two fixed batches of five in each condition. Every session requested Claude Sonnet 5 through Claude Code. Each condition ran once per batch. The calculator condition could take up to three model turns, including its final submission.

      Calculator and output validation

      The local tool accepts decimal arithmetic, square roots and ceilings with limits on size, operations and range. Each result is associated with the student ID requested by Claude. The runner accepts strict JSON, validates routes, binary scores and real student step IDs, and preserves the raw response on failure. A valid step ID alone does not establish that the citation justifies a score.

      Replay guide

      What the run can tell us

      This study measures agreement with a prespecified reference and the ability to return usable grades. It covers one question, ten designed test cases and one run per condition. A faculty grading study would need independent labels, additional questions and repeat trials.

      Planned security evaluation

      A separate pilot will compare the same solution submitted with no note, a neutral note or a request for full credit. Independent faculty scoring and model results for that comparison are pending.
